Spotify Clone 🎵

A simple Spotify Clone built using HTML and CSS.
This project recreates the basic UI of Spotify including the navbar, playlists, music cards, and responsive layout.

🚀 Features
🎧 Spotify-inspired UI
📱 Responsive design
🎨 Modern layout using CSS Flexbox/Grid
🖼 Music cards and playlist sections
🌙 Dark theme interface

🛠 Technologies Used
HTML5
CSS3
